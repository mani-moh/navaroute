What NavaRoute is — and is notNavaRoute چیست — و چه نیست

NavaRoute publishes validated public URI subscriptions, not executable core configurations or client integration. Source claims, dated socket observations and dated owner end-to-end observations are separate contracts.NavaRoute اشتراک‌های URI عمومی اعتبارسنجی‌شده منتشر می‌کند، نه پیکربندی اجرایی هسته یا یکپارچگی کلاینت. ادعاهای منبع، مشاهده‌های سوکت تاریخ‌دار و مشاهده‌های سرتاسری تاریخ‌دار مالک قراردادهای جداگانه‌اند.

✓

  • A public aggregator: it collects public proxy configs from curated sources, deduplicates them, and publishes subscription feeds.
  • Evidence-bounded: every label says what was actually observed (socket answer, Realping pass) — never more.
  • Open and reproducible: Python 3.12+ standard library only, no third-party dependencies, everything in the repo.
  • یک جمع‌آوری‌کننده عمومی: کانفیگ‌های عمومی پروکسی را از منابع گزینش‌شده جمع می‌کند، تکرارها را حذف می‌کند و فید اشتراک منتشر می‌کند.
  • محدود به مدرک: هر برچسب می‌گوید چه چیزی واقعاً مشاهده شده است (جواب سوکت، گذر Realping) — هرگز بیشتر.
  • باز و قابل بازتولید: فقط کتابخانه استاندارد Python 3.12+، بدون وابستگی ثالث، همه‌چیز در مخزن.

✗

  • Not a VPN or a server: NavaRoute runs no servers and sells nothing.
  • Not a guarantee: a listed config may be slow, dead, or blocked. Try the tested feed first.
  • Not a client: use v2rayNG, v2rayN, Hiddify or a compatible app to connect.
  • VPN یا سرور نیست: NavaRoute سروری اجرا نمی‌کند و چیزی نمی‌فروشد.
  • تضمین نیست: یک کانفیگ فهرست‌شده ممکن است کند، مرده یا مسدود باشد. اول فید tested را امتحان کنید.
  • کلاینت نیست: برای اتصال از v2rayNG ،v2rayN ،Hiddify یا برنامه سازگار استفاده کنید.

The data pipeline, stage by stageپایپ‌لاین داده، مرحله به مرحله

From a curated source list to published feeds — every stage is bounded, and every label says what was actually observed.از فهرست منبع گزینش‌شده تا فیدهای منتشرشده — هر مرحله محدود است و هر برچسب می‌گوید چه چیزی واقعاً مشاهده شده است.

1

Sources registryمنابع

sources.json — the static registry

Enabled, validated entries from the static registry. A failing or empty registry aborts the run and keeps the previous publication — zero enabled sources is a hard error, not an empty feed.ورودی‌های فعال و اعتبارسنجی‌شده از رجیستری ثابت. رجیستری خراب یا خالی اجرا را متوقف و انتشار قبلی را نگه می‌دارد — صفر منبع فعال یک خطای سخت است، نه یک فید خالی.

2

Concurrent fetchدریافت همزمان

fetch_all_sources — bounded transport

Public feeds are fetched concurrently with bounded workers, timeouts, and machine-only destinations (DNS / redirect / destination allow-lists). Source identities are claims, not endorsements.فیدهای عمومی به‌صورت همزمان با کارگران محدود، مهلت زمانی و مقصدهای فقط ماشینی دریافت می‌شوند (فهرست مجاز DNS / تغییرمسیر / مقصد). هویت منابع ادعاست، نه تأیید.

3

Parse & complete identityتجزیه و هویت کامل

parsers.py + models.py — fingerprint v1

Each supported node is parsed losslessly into a complete versioned identity (v1 fingerprint). Unsupported parameters are rejected — never stripped silently.هر گره پشتیبانی‌شده بدون افت به یک هویت کامل نسخه‌دار (اثر انگشت v1) تجزیه می‌شود. پارامترهای پشتیبانی‌نشده رد می‌شوند — هرگز بی‌صدا حذف نمی‌شوند.

4

Semantic deduplicationحذف تکرار معنایی

deduplicate_nodes

Source-claim merging over complete fingerprints condenses the raw yield to unique connections.ادغام ادعاهای منابع بر اساس اثر انگشت کامل، خروجی خام را به اتصال‌های یکتا فشرده می‌کند.

5

Socket healthcheckتست سلامت سوکت

check_nodes_health — socket only

Bounded probes (concurrency 64, timeout 3.5s) on up to 1000 prioritized nodes; UDP-style schemes (hysteria2, tuic, wireguard) are excluded. A socket answer is a dated observation — not credential verification, not end-to-end proof.تست‌های محدود (همزمانی ۶۴، مهلت ۳٫۵ ثانیه) روی حداکثر ۱۰۰۰ گره اولویت‌دار؛ طرح‌های UDP (hysteria2 ،tuic ،wireguard) حذف می‌شوند. جواب سوکت یک مشاهده تاریخ‌دار است — نه اعتبارسنجی هویت و نه مدرک سرتاسری.

6

Categorize & renderدسته‌بندی و رندر

categorizer.py — outputs + counts

balanced-500 samples protocol-balanced up to 500 rows; fastest-100 ranks the online pool by connection latency; country/category feeds are upstream claims. Round-trip render validation; one snapshot timestamp per publication.balanced-500 تا ۵۰۰ ردیف با توازن پروتکل نمونه می‌گیرد؛ fastest-100 استخر online را بر اساس تأخیر اتصال رتبه‌بندی می‌کند؛ فیدهای کشور/دسته ادعای منبع هستند. اعتبارسنجی رندر رفت‌وبرگشتی؛ یک زمان اسنپ‌شات برای هر انتشار.

7

Tier-1 Realpingتست Realping tier-1

tier1_pattn.py — every 2 hours on GitHub

PattN WebAPI Realping-tests up to 8,000 due configs per run: an end-to-end HTTPS GET through the proxy, twice 100 ms apart, 5 s connect timeout. Passers become the tested feeds; the state is pruned to live feeds so it stays bounded.WebAPI برنامه PattN تا ۸٬۰۰۰ کانفیگ سررسید در هر اجرا را Realping تست می‌کند: یک GET سراسری HTTPS از طریق پروکسی، دو بار با فاصله ۱۰۰ میلی‌ثانیه، مهلت اتصال ۵ ثانیه. گذرنده‌ها فیدهای tested می‌شوند؛ وضعیت به فیدهای زنده هرس می‌شود تا محدود بماند.

8

Tier-2 Iran testingتست tier-2 از ایران

tier2_pattn.py — owner PC, owner-triggered

The same Realping test run from inside Iran on the owner's PC. Passers become the tested-iran feeds; configs that fail on GitHub but pass from Iran are tracked as GitHub-blocked and force-included in tier 1.همان تست Realping از داخل ایران روی رایانه مالک اجرا می‌شود. گذرنده‌ها فیدهای tested-iran می‌شوند؛ کانفیگ‌هایی که در GitHub رد می‌شوند ولی از ایران می‌گذرند به‌عنوان مسدودشده در GitHub ردیابی و در tier-1 اجباری گنجانده می‌شوند.

9

Journaled publishانتشار ژورنالی

storage.py + public_git.py gate

The validated feed set replaces the public feeds atomically with interrupted-write journaling; staged files pass a quiet role gate before commit; pushes are non-forced rebases that retain human commits.مجموعه فید اعتبارسنجی‌شده به‌صورت اتمی با ژورنال‌نویسی جایگزین فیدهای عمومی می‌شود؛ فایل‌های مرحله‌بندی‌شده پیش از کامیت از دروازه نقش عبور می‌کنند؛ پوش‌ها ری‌بیس غیراجباری‌اند که کامیت‌های انسانی را حفظ می‌کنند.

10

Mirror & siteآینه و سایت

ArvanCloud mirror + public site

Base64 feeds sync to ArvanCloud Object Storage (accessible inside Iran) every 6 hours, and the public site and this explorer rebuild on every data push, so the live pages always match the repo.فیدهای Base64 هر ۶ ساعت به ArvanCloud Object Storage (قابل دسترس از داخل ایران) همگام می‌شوند و سایت عمومی و این کاوشگر با هر پوش داده بازسازی می‌شوند، پس صفحات زنده همیشه با مخزن هماهنگ‌اند.

Scheduled GitHub Actionsاکشن‌های زمان‌بندی‌شده GitHub

The pipeline runs on GitHub Actions. Writers share one concurrency group so only one publishes at a time.پایپ‌لاین روی GitHub Actions اجرا می‌شود. نویسنده‌ها یک گروه همزمانی مشترک دارند تا هر بار فقط یکی منتشر کند.

Trust boundaries and evidenceمرزهای اعتماد و مدرک

Public, claims-labeled input onlyورودی فقط عمومی و برچسب‌ادعا

Feeds are produced from public, curated registries. Source identities and country/category tags are upstream claims — validated for identity shape, not endorsed or geo-checked. No private data is crawled.فیدها از رجیستری‌های عمومی و گزینش‌شده تولید می‌شوند. هویت منابع و برچسب‌های کشور/دسته ادعای منبع‌اند — از نظر شکل هویت اعتبارسنجی شده‌اند، نه تأیید و نه راستی‌آزمایی جغرافیایی. هیچ داده خصوصی خزیده نمی‌شود.

Privacy gate before commitدروازه حریم خصوصی پیش از کامیت

Two quiet checks bound every writer: a tracked/index role gate and, immediately before commit, an exact staged-file audit.دو بررسی بی‌صدا هر نویسنده را محدود می‌کند: دروازه نقش tracked/index و درست پیش از کامیت، حسابرسی دقیق فایل‌های مرحله‌بندی‌شده.

Non-forced publicationانتشار غیراجباری

Pushes are non-forced rebased updates that retain human commits. Five failed rebase/push attempts then the writer stops — the last green publication stays in place.پوش‌ها به‌روزرسانی‌های ری‌بیس غیراجباری‌اند که کامیت‌های انسانی را حفظ می‌کنند. پس از پنج تلاش ناموفق ری‌بیس/پوش، نویسنده متوقف می‌شود — آخرین انتشار سبز سر جایش می‌ماند.

Socket observation ≠ evidenceمشاهده سوکت ≠ مدرک

online.txt is dated socket observations only; fastest-100 ranks by measured connection latency. Nothing here proves credential validity or carrier interoperability.online.txt فقط مشاهده‌های سوکت تاریخ‌دار است؛ fastest-100 بر اساس تأخیر اتصال اندازه‌گیری‌شده رتبه‌بندی می‌کند. هیچ‌چیز اینجا اعتبار هویت یا سازگاری حامل را ثابت نمی‌کند.

Tested means end-to-end, not a guaranteeتست‌شده یعنی سرتاسری، نه تضمین

tested.txt passed a real connection test on GitHub runners; tested-iran.txt passed the same test from inside Iran. A passing test is a dated observation — servers go offline, get overloaded or get blocked.tested.txt یک تست اتصال واقعی در GitHub را گذرانده است؛ tested-iran.txt همان تست را از داخل ایران گذرانده است. تست گذرنده یک مشاهده تاریخ‌دار است — سرورها خاموش می‌شوند، شلوغ می‌شوند یا مسدود می‌شوند.

Protected Iran-results boundaryمرز محافظت‌شده نتایج ایران

Any end-to-end owner evidence lives on the protected iran-results branch: reviewed tester import, pinned core, explicit attestations, and an operator-only command. No scheduled job, bot, or dependency can publish there.هر مدرک سرتاسری مالک در شاخه محافظت‌شده iran-results زندگی می‌کند: واردات تست‌کننده بررسی‌شده، هسته پین‌شده، گواهی‌های صریح و دستور فقط اپراتور. هیچ کار زمان‌بندی‌شده، ربات یا وابستگی نمی‌تواند آنجا منتشر کند.

One writer per output directoryیک نویسنده برای هر پوشه خروجی

Actions concurrency serializes scheduled master writers, but local publishers are not covered. Concurrent writers are forbidden; journal recovery makes interrupted replacement recoverable, not parallel.همزمانی Actions نویسنده‌های زمان‌بندی‌شده master را سریالی می‌کند، ولی ناشران محلی را پوشش نمی‌دهد. نویسنده همزمان ممنوع است؛ بازیابی ژورنال جایگزینی ناتمام را قابل بازیابی می‌کند، نه موازی.

Minimal dependency surfaceحداقل سطح وابستگی

Runtime: Python 3.12+ standard library only — no third-party dependencies to supply-chain-review. The project does not ship, install, or discover cores.اجرا: فقط کتابخانه استاندارد Python 3.12+ — بدون وابستگی ثالث برای بازبینی زنجیره تأمین. این پروژه هسته ارسال، نصب یا کشف نمی‌کند.

Running it yourselfاجرای آن توسط خودتان

Clone the repo (Python 3.12+, standard library only — nothing to install). Run the tests, then build the site and this explorer:مخزن را کلون کنید (Python 3.12+، فقط کتابخانه استاندارد — چیزی برای نصب نیست). تست‌ها را اجرا کنید، سپس سایت و این کاوشگر را بسازید:

git clone https://github.com/mani-moh/navaroute.git
cd navaroute
python3 -m unittest discover -s tests
python3 -m ruff check src scripts tests tools
python3 scripts/build_public_site.py --repo-root . --out site
python3 scripts/build_explorer.py --repo-root . --out docs/explorer

NavaRoute is an open-source aggregator of public proxy configs. It does not run servers, sell access, or promise that any config works.NavaRoute یک جمع‌آوری‌کننده متن‌باز کانفیگ‌های عمومی پروکسی است. سرور اجرا نمی‌کند، دسترسی نمی‌فروشد و کار کردن هیچ کانفیگی را تضمین نمی‌کند.
